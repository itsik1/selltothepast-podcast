# למכור לעבר · podcast feed

Static podcast feed for the "Sell to the Past" (למכור לעבר) show. `feed.xml`, `episodes.json`, `cover.jpg` and `audio/` are generated by `stp publish podcast` in the sell-to-the-past repo. Do not edit those by hand.

Feed: https://itsik1.github.io/selltothepast-podcast/feed.xml

## Status page (phone-friendly)

https://itsik1.github.io/selltothepast-podcast/ shows the state of the feed, Apple Podcasts, Spotify and YouTube. The `status` workflow refreshes `status.json` (on the `status` branch) twice a day and after every feed push; "Run workflow" refreshes it now.

Optional repo settings that light up more of the page:

| Setting | Where | What it enables |
| --- | --- | --- |
| `YOUTUBE_CHANNEL_ID` | Actions → Variables | upload list from the channel RSS |
| `YOUTUBE_API_KEY` | Actions → Secrets | subscribers / views (YouTube Data API v3 key) |
| `SPOTIFY_SHOW_ID` | Actions → Variables | catalog check via the public oEmbed endpoint (no key needed) |
| `SPOTIFY_CLIENT_ID`, `SPOTIFY_CLIENT_SECRET` | Actions → Secrets | optional, episode count via the Web API (needs Web API access) |

## Branding

`branding/` holds channel avatars (the character inside a time-machine clock dial, no letter) for YouTube / Spotify / Apple, `cover-en.jpg`, an English-title variant of the cover, and `time-machine-dial-*.png`, the transparent dial alone for video overlays and transitions.

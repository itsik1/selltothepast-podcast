## Reliability caveat — read before trusting the negatives

The search index did **not** surface שקם's SM-R640 page even on a domain-restricted
query against shekem-electric.co.il. It was found only because the user supplied the
URL directly.

So the positive result is confirmed, but every "not found" in the table above rests on
the same method that already produced one false negative. Another chain may stock the
model without it being indexed. Treat the negatives as weak evidence, not as absence.

The underlying cause is environmental: this sandbox's egress proxy blocks all merchant
sites, so no finding here was ever verified against a live page.
